# data/raw

The IDD-AW images are **not stored in this repository**.

To get the data:
1. Go to https://iddaw.github.io/ and follow the link to the IDD portal.
2. Register at http://idd.insaan.iiit.ac.in/dataset/download/ and request a download token (valid for 24 hours).
3. Download IDD-AW and place the files in this folder.
4. Check the dataset licence at download time.

Checksums for the downloaded files will be added here during the final project.
